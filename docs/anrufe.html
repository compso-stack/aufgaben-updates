📹 Anrufe über Home Assistant

Ein Videoanruf in KiPa klingelt normalerweise nur, wenn KiPa auf dem anderen Handy gerade offen ist. Wer Home Assistant hat, kann das ändern: Ruft das Tablet an, schickt Home Assistant eine Nachricht an die Home-Assistant-App auf dem Eltern-Handy – mit den Knöpfen „📹 Annehmen“ und „Ablehnen“. Das funktioniert auch, wenn KiPa geschlossen ist.

Was ihr braucht

  • Home Assistant zuhause, im selben WLAN wie das Tablet.
  • Auf jedem Eltern-Handy die Home-Assistant-App (Companion-App, kostenlos im Play Store), angemeldet an eurem Home Assistant. Sie meldet sich dort als Gerät an, z. B. „Pixel 8 von Anna“.
  • KiPa auf dem Tablet und auf den Eltern-Handys, mit eingeschaltetem 💬 Chat (⚙ → 🧩 Funktionen).

Einrichten

  1. Eltern-Handy: In KiPa ⚙ → 🏠 Home Assistant. Adresse eintragen (z. B. http://192.168.1.10:8123), dann „🔑 Mit Home Assistant anmelden“. Der Browser zeigt die Anmeldung eures Home Assistant – mit Benutzername und Passwort anmelden, danach geht es von selbst zurück zu KiPa. (Wer lieber will, kann stattdessen einen langlebigen Zugangsschlüssel eintragen: Home Assistant → Profil → Sicherheit → „Langlebige Zugangstoken“.)
  2. Noch auf dem Eltern-Handy: „📲 QR fürs Tablet zeigen“.
  3. Tablet: ⚙ unten rechts → 🏠 Home Assistant → „📷 QR vom Eltern-Handy scannen“.
  4. Darunter steht „📹 Anrufe über Home Assistant melden“ – der Schalter ist schon an. Bei jedem Elternteil zeigt KiPa „✅ Automatisch erkannt“. Wird ein Handy nicht erkannt: KiPa einmal auf diesem Handy öffnen oder das Handy von Hand antippen.
  5. „Test-Nachricht schicken“ – auf dem Eltern-Handy erscheint eine Nachricht mit beiden Knöpfen.

Richtig klingeln lassen

Nach der ersten Nachricht gibt es in Android den Kanal „KiPa Anrufe“: Einstellungen → Apps → Home Assistant → Benachrichtigungen → „KiPa Anrufe“ → Ton. Dort einen Klingelton wählen und „Bitte nicht stören“ übergehen erlauben.

Gut zu wissen

  • Die Nachricht verschwindet, sobald der Anruf vorbei ist, spätestens nach einer Minute. Nach 45 Sekunden ohne Antwort gilt der Anruf als verpasst.
  • Der Zugangsschlüssel bleibt auf euren Geräten. Er wird nie auf einem Server gespeichert; das Tablet bekommt ihn nur über den QR-Code.
  • Das Bild und der Ton gehen direkt von Gerät zu Gerät, nicht über Home Assistant. Unterwegs im Mobilfunknetz klappt die Verbindung nicht immer.
  • Ausschalten: am Tablet den Schalter „📹 Anrufe über Home Assistant melden“ aus, oder bei einem Elternteil „keins“ wählen.
