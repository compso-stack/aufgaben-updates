📲 Geräte mit Home Assistant verbinden

Mit Home Assistant kann KiPa Technik-Zeit direkt freischalten: Ein Kind löst im Shop Punkte ein, und schon bekommt das Handy oder die Switch die Minuten. Hier stehen nur die Schritte für die Geräte, die ihr ausgewählt habt.

Kreuzt oben an, welche Geräte eure Kinder haben.

1. Vorbereitung

  • Home Assistant läuft bei euch zuhause, im selben WLAN wie das Tablet bzw. die Handys.
  • Home Assistant ist auf dem neuesten Stand (mindestens 2026.11), dort ist der Marketplace schon eingebaut:
    Updates in Home Assistant öffnen

Die türkisen Knöpfe sind „My Home Assistant“-Links: Beim ersten Mal fragt die Seite nach der Adresse eures Home Assistant (z. B. http://192.168.1.10:8123), danach springt jeder Knopf direkt an die richtige Stelle.

📱 Android-Handys (Google Family Link)

Die Kinder-Handys müssen schon mit Google Family Link verwaltet werden (Elternkonto + Kinderkonto). Home Assistant braucht dafür zwei Teile: ein Add-on, das sich einmal bei Google anmeldet, und die Integration „Google Family Link“.

⚠️ Google hat für Family Link keine offizielle Schnittstelle. Die Integration (noiwid/HAFamilyLink) nutzt inoffizielle Wege: Google kann sie jederzeit stören, und laut ihrem Entwickler verstößt sie womöglich gegen Googles Nutzungsbedingungen. Nutzung auf eigene Gefahr – am besten mit einem eigenen Eltern-Google-Konto nur dafür.

a) Add-on „Google Family Link Auth“

  1. Add-on-Quelle hinzufügen:
    Quelle in Home Assistant hinzufügen
    (oder von Hand: Einstellungen → Apps → App installieren → ⋮ → Repositories → https://github.com/noiwid/HAFamilyLink)
  2. „Google Family Link Auth“ installieren (dauert ein paar Minuten), „Beim Start starten“ einschalten und starten.
  3. „Web-UI öffnen“ → „Start Authentication“. Wichtig: im WLAN zuhause über die lokale Adresse, nicht über eine Adresse von unterwegs.
  4. Die Seite http://<Adresse-von-Home-Assistant>:6080/vnc.html öffnen. Das Passwort dafür steht im Reiter Protokoll des Add-ons („VNC password for this start“).
  5. Im Fenster ganz normal bei Google anmelden (mit dem Elternkonto) und die Bestätigung (2FA) erledigen – das Handy dafür bereithalten, es gibt etwa 5 Minuten Zeit. Wenn „gespeichert“ erscheint, ist dieser Teil fertig.
  6. Danach das Add-on wieder stoppen. Die Anschlüsse 8099 und 6080 nie ins Internet freigeben.

b) Integration „Google Family Link“

  1. Einstellungen → Marketplace → Durchsuchen → „Google Family Link“ → installieren → Home Assistant neu starten.
  2. Integration hinzufügen:
    Family Link in Home Assistant einrichten
    → „Auto-detect (add-on or local file)“ wählen, der Rest kann so bleiben.
  3. Kurz warten: Für jedes Kinder-Handy erscheint ein Gerät.

Läuft die Google-Anmeldung irgendwann ab, meldet Home Assistant das. Dann Schritt a) 3–5 wiederholen.

🎮 Nintendo Switch

Die Switch-Integration ist in Home Assistant schon eingebaut – kein Marketplace nötig.

  1. Die Switch muss mit der App „Nintendo Switch Parental Controls“ auf einem Eltern-Handy verbunden sein (Anleitung von Nintendo).
  2. Integration hinzufügen:
    Switch in Home Assistant einrichten
  3. Home Assistant zeigt einen Link: öffnen und mit dem Nintendo-Account anmelden, mit dem die Switch verwaltet wird.
  4. Auf der Seite mit dem roten Knopf „Diese Person auswählen“ den Knopf lange drücken (am PC: Rechtsklick) → „Link kopieren“ – nicht antippen.
  5. Den kopierten Link in Home Assistant einfügen, „Senden“ und die restlichen Fragen bestätigen.

Ändert ihr später in Home Assistant die PIN der Switch, schickt Nintendo automatisch eine E-Mail – das ist normal.

🎮 PlayStation

Geht leider (noch) nicht. Home Assistant kann bei der PlayStation nur anzeigen, ob sie an ist und was gespielt wird – Spielzeit freischalten oder begrenzen kann es nicht. Spielzeit bitte weiter in der PlayStation-App einstellen.

🎮 Xbox

Geht leider (noch) nicht. Die Xbox-Integration von Home Assistant zeigt nur den Status, Bildschirmzeit lässt sich damit nicht freischalten. Spielzeit bitte weiter in der App „Xbox Family Settings“ einstellen.

Zum Schluss: KiPa mit Home Assistant verbinden

  1. Eltern-Handy: KiPa → ⚙ → 🏠 Home Assistant → Adresse eintragen (z. B. http://192.168.1.10:8123) → „🔑 Mit Home Assistant anmelden“.
  2. KiPa zeigt danach „✅ … Geräte gefunden“ – Handys mit 📱, Switch mit 🎮.
  3. Tablet (falls ihr eins habt): Eltern-Handy „📲 QR fürs Tablet zeigen“, am Tablet ⚙ → 🏠 Home Assistant → „📷 QR vom Eltern-Handy scannen“.
  4. Belohnungen: Eltern → 🎁 Belohnungen → „⏱ Technik-Zeit-Vorlagen“, oder das Kind wählt im Shop „⏱ Eigene Technik-Zeit“.

Wird ein Gerät nicht gefunden: in KiPa unter ⚙ → 🏠 Home Assistant „Trennen“ und neu anmelden, nachdem Home Assistant die Geräte angelegt hat.
